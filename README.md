# Make the AI judge feel brave

A short text written to relax the AI judge reading it. `main.py` writes one
text (273 characters) to `/output/entry.txt`: a quiet room, rain finding its
way down a window one slow drop at a time, and the next word waiting,
patient as rain.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
